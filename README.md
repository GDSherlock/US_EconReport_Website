# 观澜 · 美国宏观周报

**中文** · [EN](./README.en.md)

**观察宏观，理解变化。**

观澜（MacroWatch）是一个中英文宏观研究周报网站，持续记录美国经济、流动性、货币政策与重要事件。每期以研究判断为主线，结合数据与分析，帮助读者理解本周的变化及后续值得关注的信号。

## 研究优先的阅读体验

首页直接展示最新一期完整报告，按照「标题与摘要 → 本周核心判断 → 数据依据与分析 → 接下来关注」组织阅读。报告包含发布日期、预计阅读时长与章节目录；历史报告按年份分组、按日期倒序收录在研究归档中。

网站沿用暖白底色、衬线标题、克制的强调色、细分隔线与留白。桌面采用正文与侧边目录，手机采用单栏与折叠目录。中文导航为「最新周报 / 研究归档 / 数据图表」，英文对应「Latest report / Archive / Charts」。语言入口为轻量的「中文 · EN」文字组合，当前语言突出显示。

图表是研究的数据与证据层。独立图表页支持查阅历史趋势与统计口径；报告中的图表服务于相关章节的判断，正文始终处于核心位置。

## 页面与语言切换

| 页面 | 中文 URL | 英文 URL |
| --- | --- | --- |
| 最新周报 | `/` | `/en/` |
| 研究归档 | `/archive/` | `/en/archive/` |
| 单期报告 | `/report/YYYY-MM-DD/` | `/en/report/YYYY-MM-DD/` |
| 图表索引 | `/charts/` | `/en/charts/` |
| 图表主题 | `/charts/{topic}/` | `/en/charts/{topic}/` |
| 关于与联系 | `/contact/` | `/en/contact/` |

切换语言进入同一期报告或同一图表主题。图表锚点保留；报告章节按中英文稿的对应顺序映射，便于继续阅读。

两个首页都以最新已发布中文报告的日期选定本期。如果英文正文尚未发布或仍为草稿，英文首页和该期详情页显示待发布提示，并链接同一期中文原文。英文归档保留该期入口并标注待译；网站不会自动显示上一期英文，也不会在访问时生成机器翻译。

## 数据图表与指标解释

| 主题 | 主要指标 |
| --- | --- |
| 流动性 | 金融流动性代理量、美联储负债、TGA、逆回购、周度变化贡献 |
| 利率与收益率曲线 | SOFR / OIS、美债期限结构、实际收益率、主要国家 10 年期收益率利差 |
| 增长与需求 | 实际 GDP、ISM、高频零售与经济活动 |
| 通胀与成本 | CPI / PCE、消费者通胀预期、供应链压力 |
| 就业与工资 | 非农、失业率、平均时薪、初请与续请失业金 |
| 房地产 | 成屋销售、库存、可售月数、按揭利率 |
| 金融条件 | 金融状况与压力、MOVE / VIX、美元指数、主要货币汇率 |

图表支持历史区间选择、数据表查看，以及收益率曲线的观测日期选择。每张图表下的「指标解释与作用」先给出简要说明，展开后可查看定义、研究用途、变化解读与局限；自行构造或加工的指标另说明计算逻辑和解释边界。

中英文版本共用图表组件、历史时间序列和数据版本。报告内图表固定引用其声明的数据版本与期间；「查看最新数据与完整历史」进入当前语言的对应主题页。

历史数据初始化后，通过标准化批次由 Agent 新增或修订。更新保留旧报告引用的版本。页面数据来源标注 Wind、Bloomberg；数据更新日期与各指标统计截止期分别呈现。指标解释中的定义与方法参考链接用于说明概念，与历史数据来源区分。

## 内容与组件组织

| 内容 | 维护位置 |
| --- | --- |
| 中文报告 | `src/content/reports/YYYY-MM-DD.md`，`locale: zh`（旧稿默认中文） |
| 英文报告 | `src/content/reports/en/YYYY-MM-DD.md`，`locale: en` |
| 中文指标解释 | `src/data/indicator-guides.mjs` |
| 英文指标解释 | `src/data/indicator-guides.en.mjs` |
| 英文图表显示文案 | `src/data/chart-copy.en.mjs` |
| 共用历史数据与版本 | `src/data/macro/` |
| 共用页面与布局 | `src/components/pages/`、`src/layouts/` |
| 语言与 URL 工具 | `src/lib/i18n.mjs` |

页面使用 Astro 静态生成。中英文路由作为入口，复用同一套页面、布局、图表渲染与交互；正文和指标解释分别编辑。报告按日期关联，新报告无需手动新增路由。

更新中文周报时，同步整理完整英文稿，逐段核对数字、单位换算、比较期间与限定条件，并保持章节层级和顺序一致。双语报告的 `chartId`、`releaseId`、`range`、`selectedPeriod` 及图表顺序保持一致，只翻译 `caption` 和 `versionNote`。无法完成英文稿时，应明确保留缺译状态。

新增图表或调整指标关联时，应同步维护两种语言的解释和展示文案。校验会检查解释覆盖范围、英文图表文案及双语报告的固定图表引用，避免内容或数据版本错配。

周报正文转换、英文翻译及数据更新的 Agent Prompt 位于本地 `docs/Agent_workbook/`，周报入口为 `01_周报正文更新_Prompt.md`。该目录遵循现有忽略规则，不随仓库提交；浏览器验收范围按当次任务约定执行。

## 本地开发与校验

需要 Node.js **>= 22.19.0**。

```sh
npm install
npm run dev
```

```sh
npm run data:inventory
npm test
npm run check
npm run build
node scripts/check-chart-routes.mjs
node scripts/check-i18n-routes.mjs
npm run preview
```

`data:inventory` 输出实际维护的指标、最新有效期间与数值、图表及关联关系。构建前自动执行数据校验；路由检查脚本在构建后运行。

部署到子路径时，可通过 `PAGES_BASE_PATH` 配置路径，通过 `PAGES_SITE` 配置站点地址；两个路由检查脚本使用相应的 `--base /subpath/` 参数。本地数据写入、构建和预览不会自动推送或部署。

本站内容仅供研究与交流，不构成投资建议。联系信息与完整免责声明见网站「关于与联系」页面。
