# 观澜 · 美国宏观周报

**观察宏观，理解变化。**

观澜是一个以美国宏观研究为核心的中文周报网站，持续记录流动性、经济基本面、货币政策与重要事件的变化。每期从核心判断出发，结合数据与分析，帮助读者理解本周发生了什么、变化意味着什么，以及接下来值得关注的信号。

## 最新周报

首页直接呈现最新一期完整报告。读者可以先通过标题、摘要与「本周核心判断」掌握本期主线，再沿章节深入阅读数据依据和分析解释。

报告页面包含发布日期、预计阅读时长、章节目录及完整正文。文末的「接下来关注」汇总后续需要跟踪的数据与事件，让每周的观察保持连续。

## 研究内容

周报围绕四个研究领域展开，具体内容随当周数据与事件调整。

| 研究领域 | 主要关注内容 |
| --- | --- |
| 流动性与高频 | 美联储负债、财政部一般账户（TGA）、逆回购与短端利率，以及消费、金融条件和就业高频信号。 |
| 美国经济 | 就业、工资、住房、小企业信心与供应链压力，结合月度数据分析增长动能与成本约束。 |
| 央行政策 | 美联储的政策信号与利率路径，同时观察欧洲央行、日本央行的政策变化。 |
| 重要事件 | 地缘冲突、能源运输、全球债券市场及产业动态，关注它们对增长、通胀和金融条件的传导。 |

内容遵循「结论先行—数据支撑—分析解释」的阅读层级。核心判断帮助快速把握方向，数据段落与必要的表格提供依据，完整分析保留判断的条件、分歧与待观察因素。

## 研究归档

「研究归档」按年份分组、按时间倒序排列已发布的周报。每条记录展示报告日期、标题、摘要与预计阅读时长，方便读者回顾不同阶段的研究主题。

每期报告都有独立的阅读页面，可用于收藏、分享和后续查阅。新一期发布后，首页展示最新报告，往期内容继续保留在归档中。

## 阅读体验

- **桌面阅读**：正文保持适合中文长文的宽度，侧边目录随阅读位置高亮当前章节，并展示对应子目录。
- **手机阅读**：采用单栏布局与折叠目录，滚动时仍可快速切换章节。
- **信息层级**：通过标题、段落、数据引用和细分隔线组织内容，让判断、证据与解释容易区分。
- **视觉风格**：暖白底色、宋体标题、克制的色彩与留白，突出研究内容本身。

## 如何阅读

时间有限时，可以先读首页摘要与核心判断；希望深入了解某一主题时，可通过目录直接进入相关章节；需要回顾研究脉络时，可从归档打开往期报告，对照不同时点的数据与判断。

观澜以每周完整研究报告为中心，让宏观变化既能被快速理解，也能被持续记录。

## 数据图表

“数据图表”是周报的数据与证据层。七个独立主题覆盖流动性、利率、增长、通胀、就业、房地产与金融条件，可查看历史趋势、统计口径和来源。首页继续展示最新一期完整报告。

报告内图表固定引用该期的数据版本，点击“查看最新数据与完整历史”可进入对应主题页。图表数据初始化自提供的美国宏观数据库，之后通过标准化批次由 Agent 新增或修订；更新不会覆盖旧报告所引用的版本。

运行 `npm run data:inventory` 可输出当前全部指标、最新有效期间/数值、图表及关联关系。利率主题包含主要国家10年期利差；金融条件主题包含美元指数和美元兑主要货币汇率。页面来源统一标注 Wind、Bloomberg，数据更新日期与各指标的统计截止期分别保留。

周报转换与数据更新的 Agent Prompt 保存在本地 `docs/Agent_workbook/`。该目录遵循现有忽略规则，不随代码提交；浏览器验收由用户执行。

每幅主题图表下提供“指标解释与作用”：默认展示简短用途，展开可查看指标含义、变化解读、研究局限，以及派生指标的计算逻辑。解释统一维护在 `src/data/indicator-guides.mjs`，不会改变历史观测或报告引用版本。新增图表或修改关联指标时，必须同步补充解释；构建会检查覆盖范围。定义与方法参考链接用于辅助理解，与图下注明的数据来源分开展示。

开发环境要求 Node.js >=22.19.0。运行 `npm test`、`npm run check` 和 `npm run build` 验证；构建前自动检查全部数据版本。`npm run preview` 启动本地构建预览。数据批次写入和本地构建均不会自动推送或部署。


## 中英文版本

中文 URL 保持不变；英文使用 `/en/`，如 `/en/archive/`、`/en/report/2026-09-11/` 与 `/en/charts/rates/`。语言切换保留同一期报告/同一图表主题，图表锚点保留，报告章节按对应顺序映射。

- 中文报告：`src/content/reports/YYYY-MM-DD.md`（`locale: zh`，旧稿默认 zh）；英文：`src/content/reports/en/YYYY-MM-DD.md`（`locale: en`）。日期是同一期内容的关联键；两者独立编辑，保持章节层级和次序一致。
- 最新一期以最新已发布中文报告日期为准。英文未发布或 draft 时，对应英文首页/报告页明确提示并链接该期中文；不回退到上一期、不实时机器翻译。英文归档仍列出该期并标注待译。
- 页面路由为薄入口，复用 `src/components/pages/`、layouts 与所有图表组件。语言 URL 统一由 `src/lib/i18n.mjs` 处理，包括部署子路径。
- 指标解释分别维护 `src/data/indicator-guides.mjs` 与 `src/data/indicator-guides.en.mjs`。英文图表显示文案在 `src/data/chart-copy.en.mjs`；缺失英文图表文案会使检查/构建失败，避免静默混用语言。
- 历史序列和 release 只存一份。双语报告 charts 的 chartId、releaseId、range、selectedPeriod 与标记顺序必须相同，只翻译 caption 和 versionNote。
- 从中文原稿发布时，先整理完整中文再翻译完整英文，逐段复核所有数值、单位换算和条件判断，保持章节顺序；无法完成英文时明确保留缺译状态。详细 Agent Prompt 仍在被忽略的 `docs/Agent_workbook/01_周报正文更新_Prompt.md`。
- 校验：`npm test`、`npm run check`、`npm run build`、`node scripts/check-chart-routes.mjs`、`node scripts/check-i18n-routes.mjs`。部署子路径构建可传 `--base /subpath/` 给两个路由校验脚本。
