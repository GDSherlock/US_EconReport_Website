# Chart Pages 手动验收清单

浏览器验收由用户执行。先在仓库根目录运行 `npm run build` 和 `npm run preview`，使用命令实际输出的端口。本次预览地址为 `http://127.0.0.1:4323/`；若已有服务占用端口，以最新输出为准。

## 1. 首页仍以周报为中心

- 打开 `/`，首先看到最新周报标题、摘要与核心判断，未出现 Dashboard、行情卡片墙或图表汇总页。
- 原有章节顺序、侧边/移动目录、全文与“接下来关注”保留。
- 导航依次为“最新周报 / 研究归档 / 数据图表”，点击品牌返回最新周报。
- `/report/2026-09-11/` 与首页呈现同一期报告和相同三幅图；`/report/2026-09-05/` 保持原报告，没有自动添加图表。

## 2. 目录与七个主题

- `/charts/` 只包含主题说明和七个入口。
- 七页都能直接访问及刷新：`liquidity`、`rates`、`growth`、`inflation`、`labor`、`housing`、`financial-conditions`，均位于 `/charts/` 下。
- 图表数量分别为 3、4、3、4、4、3、3，共 24 幅；上下分面属于同一个图表。
- 每页标题正确，本页目录能跳到对应图表，导航不错误地高亮“最新周报”。

## 3. 报告中的三幅图

- 流动性章节出现“金融流动性规模”；8月就业章节出现“新增非农就业”；成屋销售章节出现对应销量图。
- 图表位于相关正文中，不遮住正文、数据表或目录，不取代原分析。
- 三图都说明“根据 2026-09-11 数据库版本补充；非原始发布快照”。
- 点击“查看最新数据与完整历史”，进入正确主题并定位对应图表。
- SOFR/OIS 正文没有被改写，也没有加上可能与正文冲突的图。

## 4. 图表交互

- 主题图表切换“1年 / 3年 / 5年 / 全部”后，横轴、曲线和当前区间数据表同步变化，按钮选中状态明确。
- 收益率曲线切换观测日期后，图上日期与数值一起变化；不能把多天的数据混成一条曲线。
- 鼠标/触屏查看图形时可读到对应期间和数值；用 Tab、Enter 可操作范围按钮和数据表。
- “查看数据表”展开后，期间、数值、单位与图形一致；空值为“—”，不显示为 0。
- 图表不出现 NaN、Infinity、断裂标签或空白错误页面。

## 5. 可核对的数据样例

- 净流动性：2026-09-09 为 **54,599.05 亿美元**，前周为 **53,638.11 亿美元**；周变化 **+960.94 亿美元**。
- 非农：2026-08 为 **16.2 万人**；2026-07 为 **2.1 万人**。
- 成屋销售：2026-08 为 **398 万套**，标明季调折年数。
- 初请与续请截止日分别为 **2026-09-04、2026-08-28**，不被统一改写成文件日期。
- SOFR/OIS 主题图中，2026-09-04 OIS 为 **3.8092%**、利差 **-15.92bp**，旁边保留与报告有差异的说明。
- 每幅图可以展开查看指标频率、单位、季调信息和附件来源位置。

上述数值用于核对本次附件初始化结果，不代表外部官方数据已被独立验证。

## 6. 桌面与移动阅读

- 建议分别检查桌面约 1440px、手机 390px 和窄屏 320px。
- 全站保持暖白底、宋体标题和克制的研究网站排版；正文没有被图表压缩为窄列。
- 页面无整体横向滚动，图例不遮住坐标，日期和刻度可读。数据表可以在自己的区域滚动。
- 手机目录可展开、跳转后可继续阅读；报告图表在窄屏上不缩成无法辨认的小图。
- 禁用 JavaScript 后仍有默认图、来源与可展开数据表；打印预览保留图表和来源。

## 7. 版本行为（已覆盖自动测试）

- Agent 更新新增版本后，主题页使用新版本；旧报告的 releaseId、数据与定义不被覆盖。
- 修改历史值需要 revision reason；无来源、重复/非法期间、单位不匹配或哈希不一致会导致校验失败。
- 本地更新命令不自动提交、推送或部署。

如发现问题，记录页面路径、屏幕宽度、操作步骤和实际表现即可，便于直接定位修复。
