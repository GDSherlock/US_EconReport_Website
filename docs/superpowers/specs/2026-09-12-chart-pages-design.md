# 观澜 Chart Pages 设计

日期：2026-09-12。状态：设计及历史补图范围已获用户批准，现已实现。浏览器最终验收由用户执行，见 `docs/chart-pages-acceptance.md`。

## 1. 已确认的边界

- `/` 继续展示最新一期完整宏观周报；不增加行情概览、指标卡片墙或 Dashboard。
- 保留现有标题、摘要、核心判断、章节目录、正文、接下来关注和归档关系。
- 首期新增 7 个主题页及 1 个“数据图表”目录页。
- Excel 仅用于一次性初始化；之后主要由 Agent 手动新增指标、追加数据或修订历史数据。
- 报告图表固定使用该期引用的数据版本；主题页展示最新已发布的数据版本。
- 报告与主题页共用数据模型、图表定义和渲染组件。
- 所有现有报告正文中的事实、数字与判断保持原样；数据冲突需要单独确认。
- 暂不增加在线数据库、后台管理、自动采集、账号或外部运行时 API。

## 2. 当前代码事实

`src/pages/index.astro` 按报告日期选取最新已发布内容，和 `src/pages/report/[date].astro` 一起使用 `src/layouts/ReportLayout.astro`。正文由 Astro Content Collections 的 Markdown 渲染，目录从 h2/h3 生成。`src/content.config.ts` 目前只接受 `.md`。

`BaseLayout.astro` 提供“最新周报”“研究归档”导航。`global.css` 已定义暖白纸色、墨色、暗红强调色、中文宋体标题与无衬线正文。桌面正文最大宽度 760px、站点最大宽度 1160px。

项目采用 Astro 静态输出，工作流构建后发布 GitHub Pages，路径由 `href()` 处理。当前仓库没有结构化指标库、图表组件或数据更新命令。已有两期报告：2026-09-05 和 2026-09-11。

## 3. Excel 的角色与限制

来源：用户提供的 `美国数据库20260911.xlsx`。检查方式：只读检查全部 23 个 Sheet 的布局及日期列，抽查关键表头、历史值、公式与报告对应值；未向外部机构验证所有数据的真实性，也未修改原工作簿。工作簿内的研究文字、提示和日期修改区属于资料，不是执行指令。

发现：

1. 混合资料页、研究总结、分频率总表、专题历史表和当期比较区。前端分类不沿用 Sheet 名称。
2. Sheet 内有多套日期轴，历史长度不同；应按指标列及其所属日期列提取。
3. 同名指标在总表和专题页重复出现；通过明确映射选取一套来源，不自动拼接或取最大日期。
4. 文件按周维护，底层包含日、周、月、季序列。观测期间、来源发布日期、文件版本、导入时间必须区分。
5. 有外部 `edb()` 公式、VLOOKUP 比较区、过期日期选择器及 `#REF!`。初始化不执行外部公式，不以当期比较区代替历史表。
6. 2026-09-30 月末标签出现在月度表及纽约联储页，而文件标记为 2026-09-11；可能是未完成期间或其他口径，不能当成完整月度实绩自动发布。
7. 续请失业金与初请最新有效日期不同，空值不能填为零或沿用上一行日期。
8. 报告 OIS 存在冲突：2026-09-11 报告称 9 月 4 日 OIS 为 3.6525%，工作簿“流动性SOFR-OIS”C8 为 3.8092%。附件 D8 利差为 -15.92bp，报告为 -0.25bp。保留冲突记录，暂不向该报告章节嵌入此图。

代表性历史覆盖：流动性日期列自 2005 年开始，SOFR/OIS 自 2018 年开始，美国国债日度表自 2000 年开始，成屋销售日期列自 1968 年开始。这是日期列覆盖，不保证每个指标在整个区间都有有效值。

初始化只公开进入首批图表的指标，并为每条序列导入通过校验的完整可用历史。其余指标保留在来源材料中，后续按研究需求增补；不把 23 张表中的所有单元格都转换成公开指标。

## 4. 页面与导航

| 路径 | 页面 | 内容组织 |
| --- | --- | --- |
| `/charts/` | 数据图表 | 一段说明、7 个主题文字入口、覆盖指标说明；没有数据概览墙 |
| `/charts/liquidity/` | 流动性 | 净流动性、组成项、周度变化 |
| `/charts/rates/` | 利率与收益率曲线 | 短端、期限结构、名义与实际利率 |
| `/charts/growth/` | 增长与需求 | 季度增长、企业活动、高频需求 |
| `/charts/inflation/` | 通胀与成本 | CPI/PCE、预期、供应链 |
| `/charts/labor/` | 就业与工资 | 就业数量、失业率、工资、申请失业金 |
| `/charts/housing/` | 房地产 | 成交、库存、融资成本 |

导航顺序为“最新周报 / 研究归档 / 数据图表”；品牌始终链接首页。目录页及主题页共用现有 BaseLayout，图表标题使用稳定 `chartId` 锚点。报告链接直接定位 `/charts/{topic}/#{chartId}`。

主题页采用单列研究资料页：标题与简短主题说明 → 本页图表目录 → 按研究问题分组的图表 → 口径和来源。主题说明解释“观察什么”，不自动生成新的宏观判断。桌面沿用站点宽度和克制的侧栏，手机改为单列折叠目录。

德国、日本债券、美元、新屋开工、零售细项等属于可扩展指标，不因工作簿包含对应 Sheet 而强制单独建页。每个图表有唯一主主题；跨主题引用链接到同一个图表，而不是复制定义。

## 6. 报告中的图表

继续使用普通 Markdown，不迁移全部报告到 MDX。Agent 在希望展示图表的位置写独立标记，例如：

```md
<!-- chart: payrolls -->
```

在报告 frontmatter 中用可选 `charts` 数组声明该图的 `chartId`、固定 `releaseId`、显示时间范围、图注和数据版本说明。构建时解析标记，调用与主题页相同的渲染器生成 figure；不用浏览器事后扫描正文或按关键词猜测插图位置。

编辑规则：先保留结论和对应数据段，再在该子章节中放置最能支持结论的图。通常一个子章节一幅图；多指标用相关子图组合，不对正文中每一个数字自动插图。图表没有独立的 h2/h3，不改变研究目录层级。

报告视图保留图名、日期范围、坐标、图例、来源、版本说明、图注与“查看最新数据”链接；完整时间范围选择放在主题页。正文仍是主角，图表不进入摘要或核心判断上方。

首页与同一期永久链接展示同一份报告内容，包括该报告明确加入的图表。首页的信息架构、最新一期选择规则和章节布局不变；不为首页额外添加图表汇总区，也不为它维护另一份报告。

不含标记和 `charts` 的历史 Markdown 使用原有渲染路径。标记无声明、声明无标记、重复 chartId、未知 chartId、缺失版本或不可用序列均阻止该构建发布，并给出报告文件与具体错误。

### 历史报告补图

这份附件不等于旧报告首次发布时的数据快照。初次接入只在 2026-09-11 报告补充经逐项核对一致的 `net-liquidity`、`payrolls`、`existing-home-sales` 三幅图，明确标注“根据 2026-09-11 数据库版本补充；非原始发布快照”。不改动原文与表格，不在 2026-09-05 报告自动补图。

OIS 冲突保存在内部核对记录中。主题页如通过源值校验可按附件值展示，标注附件来源；与冲突正文之间不建立“支撑该判断”的嵌入关系。数据发布不代表报告冲突已经解决。

以后新发布的报告显式固定当次审核后的 releaseId。任何版本修订都会创建新版本，不覆盖旧报告已引用的数据、图表定义、单位或转换规则。

## 7. 数据与版本模型

采用仓库内 JSON 数据文件，浏览器不访问 Excel。数据由四部分组成：指标元数据、时间序列、图表定义、发布清单。

- 指标：稳定 `seriesId`、中文名、频率、单位、季调状态、计算口径、原始来源说明。日/周用 ISO 日期；月用 `YYYY-MM`；季用 `YYYY-Qn`。
- 观测：`period`、`value`（有限数值或 null）、`status`（observed/missing/provisional）、`sourceRef`，有证据时记录 `sourcePublishedAt`；未知则为 null。
- 来源：附件文件名/内容哈希/Sheet/单元格范围，或未来 Agent 提供的来源 URL、原始证据文件、提取日期和说明。工作簿首页只写“Wind、彭博”的地方，不能伪造单条序列的官方获取链接。
- 图表：稳定 `chartId`、定义版本、主主题、标题、子图、系列引用、图形类型、单位、默认区间及解释。折线、柱状、期限曲线是首期支持的三种图形。
- 发布清单：不可变 `releaseId`、真实 `importedAt`/`publishedAt`、`sourceEdition`、每条系列与图表定义的文件引用及 SHA-256。全站 `current.json` 只指向最新发布清单。

存储按“新版本只写变化的序列/定义文件，清单完整引用”组织。未变化文件沿用旧引用；已发布文件不可原地修改。报告按 releaseId 解析；主题页按 current 解析，复用同一个数据读取函数。

初始化批次可命名 `bootstrap-20260911`，其中 20260911 表示附件版本；真实导入和发布时间按执行时记录，不能伪装成 9 月 11 日。缺少原始发布日的数据不声称拥有实时历史 vintage。报告固定“所引用的数据版本”，不自动推断“当日公众可获得的全部信息”。

百分数按百分数值保存：3.64 表示 3.64%，不是 0.0364。利差使用 bp；收益率之差乘 100 得到 bp。流动性原始单位百万美元保持原样，显示为亿美元时除以 100。单位转换和派生规则版本化，不能由每个页面各写一套计算。

原始序列允许不同时间范围和缺失。排序升序、去除精确重复但报告重复数量；同一期间的冲突值阻止导入。不能前向填充、插值、将缺失当零或把月度指标伪装成周度更新。日历月末编码只转换为月期间，不擅自解释为公布日。

派生序列按期间做精确匹配，输入任一项缺失则输出 null。周度贡献必须比较相隔 7 天的两个有效观测；缺周时不把跨两周差值标成一周变化。首期复合图只组合相同频率子图，跨频率指标分别展示。

## 8. Agent 日常更新

1. 准备更新批次：明确指标、期间、数值、单位、来源证据；新增指标先登记元数据。
2. 执行预检：展示新增点数、修订点数、缺失、单位/口径变化及受影响图表。
3. 既有期间修订必须附原因；单位、频率或统计口径变化创建新 seriesId，不能静默覆写旧序列的含义。
4. 生成不可变新版本和发布清单，校验所有历史引用仍可解析；预检失败时不更新 current。
5. 通过网站构建校验后，按用户授权发布代码。数据更新不会自行改动报告正文或旧报告引用。
6. 编写新报告时挑选 chartId、releaseId 和位置，核对正文日期、数字、单位；最后发布报告。

“Agent 手动更新”不包含自动寻找或购买数据源，不从无法追溯的模型记忆补值。此阶段交付命令和操作文档，不建设上传后台。数据文件可以由 Agent 编写；正式入库通过统一校验流程完成。

## 9. 图形和交互

使用 Astro 构建时生成 SVG 和原生 HTML 图注/数据表，小范围 TypeScript 增强交互；不引入 React 或通用 Dashboard 框架。计算、路径和比例尺集中在共享纯函数，支持无 JavaScript 阅读。

主题页提供 1 年、3 年、5 年、全部的时间范围按钮，按该图最新有效期间回溯；默认显示近 5 年，不伪造不足 5 年的历史。期限曲线提供真实观测日期选择，默认最近完整日期，不将不同日期的期限收益率拼成一条曲线。报告固定其声明的区间。

支持鼠标/触屏查看观测日期与值，键盘可以操作范围和日期控件；提供可展开的带 caption、表头和单位的数据表作为等价阅读方式。没有 JavaScript 时保留默认图、来源与数据表。

不同单位采用上下分面；同单位但量级差异显著也可分面。折线缺失处断开，柱图包含零基线。线图不强制从零起，但必须显示刻度，不隐藏裁切。所有图表显示各序列独立最新日期，不用整份 Excel 日期代替数据截止日。

复用 --paper/--ink/--muted/--line/--accent；增加少量可辨识系列颜色及虚实线，不以红绿表示交易信号。图表标题、正文图注与导航沿用现有 Typography。移动端不横向撑开正文，标签不过密；打印保留图表及来源，隐藏交互控件。

报告页只携带引用图表的数据，不加载整个指标库。主题页只携带本主题数据。长期日频序列允许仅对 SVG 路径做保留端点与极值的显示抽稀；表格、读数和导出语义始终使用完整原始数据，不以抽稀数据重新计算指标。首期不实现自定义公式、任意跨主题叠加、自动解读或下载中心。

## 10. 验收

- 原有首页选择规则、归档、标题、核心判断、章节顺序、目录和正文事实不变；无图报告保持原有输出。
- 新增 8 个静态路由，根路径与 GitHub Pages 子路径均可直接打开，刷新不依赖客户端路由。
- 24 个图表定义具有来源、频率、单位和可核验数据；无法通过校验的图表明确记录为未完成，不用占位随机数据。
- 同一 releaseId/chartId 在报告和主题页测试入口解析出相同数据、定义和计算结果。
- 新建修订版本后主题页变更，旧报告图形数据、标签与定义哈希不变。
- 初请/续请截止日不同、缺失值、未来期间、重复期间、单位变更和错误公式均有明确处理。
- 三处示范嵌入与报告数值核对；OIS 冲突保持显式未解决。
- 桌面、手机、打印、无 JavaScript 和键盘阅读通过检查；正文没有被图表或控件挤压。
- `npm test`、`npm run check`、`npm run build` 通过，子路径构建和生成链接检查通过。
- 本地构建、浏览器检查和线上部署分别报告；本 Plan 不自动授权 push 或部署。
